프로젝트: AI 패션 코치

문제 정의

자신의 패션 스타일에 대해 즉각적이고 객관적인 피드백을 받을 창구가 부족했습니다. 또한, 새 옷이 자신과 잘 어울릴지 미리 확인하기 어려웠습니다.

목표

Gemini API를 활용하여, 사용자 사진 기반의 실시간 패션 분석, 가상 조합, 맞춤형 음악 추천까지 제공하는 '개인 맞춤형 AI 스타일리스트 앱'을 구현합니다.

프로젝트 상세

'AI 패션 코치'의 기술적 설계와 사용자가 경험하는 핵심 기능들을 자세히 살펴봅니다. 탭을 클릭하여 아키텍처 다이어그램과 각 기능의 상세 설명을 확인해 보세요.

애플리케이션 아키텍처

Flutter를 사용하여 Android/iOS 크로스플랫폼 모바일 앱으로 설계했습니다.
- AI (Gemini): 핵심 AI 로직은 Google Gemini API (gemini-2.5-flash)로 분리하여, 앱은 이미지와 프롬프트를 전송하고 구조화된 텍스트 응답을 받는 방식으로 구현했습니다.
- Local DB (Hive): 사용자의 분석 내역 저장을 위해, 별도 서버 없이 가볍고 빠른 로컬 NoSQL 데이터베이스인 Hive를 채택했습니다.

핵심 기능 1: 구조화된 AI 패션 분석 및 피드백

- 사용자가 갤러리에서 사진을 업로드하거나 앱 내 카메라로 직접 촬영합니다.
- Gemini API에 이미지와 함께 `[SCORE]`, `[MESSAGE]`, `[GOOD_POINTS]` 등 사전에 정의된 태그를 포함한 프롬프트를 전송합니다.
- AI가 반환한 구조화된 텍스트를 앱에서 파싱(parsing)하여, 점수와 멘트는 즉시 보여줍니다.
- '좋은 점', '아쉬운 점', '개선 제안' 등 상세 피드백은 사용자가 클릭 시 펼쳐볼 수 있는 `ExpansionTile` UI로 제공하여 UX를 개선했습니다.

핵심 기능 2: 카메라 연동 및 자동 분석 실행

- `camera` 패키지를 사용하여 앱의 첫 번째 탭에 실시간 카메라 프리뷰를 구현했습니다.
- `CameraController`를 통해 전/후면 카메라 전환 기능을 구현하고, 화면 비율이 찌그러지지 않도록 `AspectRatio`와 `Transform.scale`을 조합하여 화면을 최적화했습니다.
- 사진 촬영 시(`onPictureTaken` 콜백), 해당 이미지 파일을 '내 스타일 분석' 탭으로 즉시 전달하고, 탭을 자동으로 이동시킨 뒤 AI 분석(`_runStyleAnalysis`)을 바로 실행하여 사용자 동선을 최소화했습니다.

핵심 기능 3: 로컬 DB 연동 및 PDF 공유

- 모든 분석 결과(이미지 경로, 텍스트, 유튜브 검색어 등)는 Hive 로컬 데이터베이스에 `HistoryItem` 객체로 저장됩니다.
- '분석 내역' 화면에서 저장된 기록을 탭(스타일/조합)으로 분리하여 볼 수 있으며, 즐겨찾기(⭐) 필터링 및 삭제가 가능합니다.
- 내역 상세 보기 시, `pdf` 패키지를 사용하여 저장된 텍스트와 이미지를 PDF 파일로 동적 생성합니다.
- 한글과 이모티콘 깨짐 현상을 방지하기 위해 커스텀 폰트(Noto Sans KR)를 PDF에 내장(embed)하고, `share_plus` 패키지를 통해 생성된 PDF 파일을 공유합니다.

회고 및 배운 점

프로젝트를 완성하는 것도 중요하지만, 그 과정에서 무엇을 기여하고 배웠는지 정리하는 것은 더 중요합니다. 이 섹션에서는 저의 기여, 프로젝트의 성과, 그리고 회고를 공유합니다.

나의 역할 및 기여

  • Flutter 기반의 전체 애플리케이션 아키텍처 설계
  • Gemini API 연동 및 AI 응답 파싱 로직 구현
  • Hive 데이터베이스 스키마(HistoryItem) 설계 및 CRUD 로직 구현
  • pdf 패키지와 커스텀 폰트를 활용한 PDF 리포트 생성 및 공유 기능 구현

결과 및 성과

  • '실시간 이미지 기반 패션 피드백'이라는 핵심 가치를 제공하는 모바일 앱 개발 완료
  • 로컬 DB(Hive) 연동으로 사용자 데이터의 영구 보존 및 활용성 확보
  • 카메라, 갤러리, AI, PDF 생성 등 다양한 네이티브 기능과 API를 Flutter 앱 하나에 성공적으로 통합

배운 점 (What I Learned)

Gemini API에 정교한 프롬프트를 전송하여, 단순 텍스트가 아닌 구조화된 데이터(점수, 멘트, 피드백 항목 등)를 받아 파싱하는 멀티모달 프롬프트 엔지니어링의 중요성을 이해했습니다.

개선할 점 (What to Improve)

API 키 보안: 현재 API 키가 앱 내(`gemini_api_key.dart`)에 포함되어 있어 보안에 매우 취약합니다. 향후 Firebase Cloud Functions 같은 백엔드 서버를 구축하여 API 키를 서버에 안전하게 보관하고, 앱은 이 개인 서버와 통신하도록 아키텍처를 개선해야 합니다.
